## 按论文阶段速查

### 选题阶段

```
不知道研究什么 → deep-research (socratic)
有方向想评估   → doubao-academic-evaluator (想法评估)
想摸清领域     → doubao-academic-researcher
```

### 调研阶段

```

中文文献调研   → doubao-academic-researcher
系统性综述     → deep-research (systematic-review)
比较论文       → deep-research (three-way-scan)

```

```

自动全流程     → academic-pipeline
```

### 评审阶段

```

```

### 修订阶段

```

```

## 常用组合命令模板

### 模板 1：英文论文全流程

```
1. Guide my research on [主题]
2. Research [研究问题] comprehensively
3. Write a paper on [研究问题]
4. Review this paper: [论文]
5. Revise based on review comments: [评审意见]
6. Verification review
7. Convert to LaTeX + Generate AI disclosure
```

### 模板 2：中文论文全流程

```
1. 帮我调研[方向]的研究现状
2. 帮我评估这个想法：[研究问题]
3. 帮我写一篇中文论文：[研究问题]
4. 投稿前帮我审一遍这篇论文
5. 帮我润色这篇论文
```

### 模板 3：已有草稿自检

```
1. 投稿前帮我挑挑硬伤：[论文]
2. 模拟同行评审这篇论文
3. 根据评审意见修改
4. 验证修订是否到位
5. 检查引用 + 格式转换
```

### 模板 4：学生读论文找方向

```
1. 精读这篇论文：[论文链接/标题]
2. 比较这三篇论文：[论文1] [论文2] [论文3]
3. 调研[方向]的研究现状
4. 引导我找到研究问题
5. 评估这个研究想法值不值得做
```
