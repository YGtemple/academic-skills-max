# 03 · 典型工作流路径

> 4 条从 0 到 1 的完整工作流，每一步都明确「用什么技能、什么模式、产出什么、下一步是什么」。

---

## 路径 A：从 0 到 1 发一篇英文论文（重型管线）

> 适用场景：投国际期刊 / SCI / 顶会，需要严格学术格式和 LaTeX 输出

### 第 1 步：厘清研究方向

**技能**：`deep-research`
**模式**：`socratic`
**输入**：你的模糊想法或兴趣领域
**产出**：
- 精炼后的研究问题（FINER 标准）
- 研究范围边界
- 初步方法论建议

**怎么做**：
```
Guide my research on [你的研究方向]
帮我厘清研究方向：我对[领域]感兴趣，但还不确定具体研究什么
```

**判断标准**：当你能清晰说出「我的研究问题是 X，我打算用 Y 方法，预期贡献是 Z」时，这一步完成。

---

### 第 2 步：系统性文献调研

**技能**：`deep-research`
**模式**：`full`（或 `systematic-review` 如果需要 PRISMA 标准）
**输入**：第 1 步形成的研究问题
**产出**：
- APA 7.0 完整研究报告
- 标注书目（含来源分级验证）
- 主题综合 + 研究空白识别
- 矛盾点与争议梳理

**怎么做**：
```
Research [你的研究问题] comprehensively
对[研究问题]做完整的系统性文献调研
```

**关键检查**：
- ✅ 文献是否覆盖了该领域的核心工作？
- ✅ 是否识别了研究空白？
- ✅ 来源是否经过验证（无掠夺性期刊、无幻觉引用）？

---

### 第 3 步：评估研究想法（可选但推荐）

**技能**：`doubao-academic-evaluator`
**模式**：想法评估
**输入**：研究问题 + 文献调研结果
**产出**：
- 新颖性打分
- 可行性评估
- 潜在风险与改进建议

**怎么做**：
```
帮我评估这个研究想法值不值得做：[你的研究问题]
```

**判断**：如果评估结果是「值得做」，继续下一步；如果有重大问题，回到第 1-2 步调整方向。

---

### 第 4 步：写完整论文

**技能**：`academic-paper`
**模式**：`full`
**输入**：研究问题 + 文献基础 + （可选）你的数据/实验结果
**产出**：
- 完整论文草稿（IMRaD 或其他选定结构）
- 双语摘要（中文繁体 + 英文）
- 引用列表（5 种格式可选）
- 图表代码（如果有定量结果）
- 内部 5 维自评报告 + 最多 2 轮修订

**怎么做**：
```
Write a paper on [你的研究问题]
帮我写一篇关于[主题]的论文
```

**配置访谈会问你**：
- 论文类型（期刊文章/会议论文/综述/案例研究等）
- 学科领域
- 目标期刊（可选）
- 引用格式（APA 7 / Chicago / MLA / IEEE / Vancouver）
- 输出格式（LaTeX / DOCX / PDF / Markdown）
- 目标字数
- 语言

**8 个阶段自动执行**：
1. 配置访谈 → 2. 文献策略 → 3. 结构设计 → 4. 论证构建 → 5. 全文起草 → 6. 引用+摘要（并行）→ 7. 内部评审 → 8. 格式化

---

### 第 5 步：模拟正式同行评审

**技能**：`academic-paper-reviewer`
**模式**：`full`
**输入**：第 4 步产出的完整论文
**产出**：
- 5 份角色分离的评审报告
  - 期刊适配评审人
  - 方法学评审人
  - 领域评审人
  - 跨学科评审人
  - 魔鬼代言人
- 编辑决策信（Accept / Minor / Major / Reject）
- 修订路线图（不可变核心 + 作者裁决记录）

**怎么做**：
```
Review this paper: [粘贴论文或提供文件]
帮我模拟同行评审这篇论文
```

**关键**：评审人只读不改，所有输出都是独立文档。

---

### 第 6 步：根据评审意见修订

**技能**：`academic-paper`
**模式**：`revision`
**输入**：原论文 + 第 5 步的评审报告 + 修订路线图
**产出**：
- 修订后的论文
- 修订日志（记录每处改动）
- 应用报告

**怎么做**：
```
Revise this paper based on the review comments: [评审意见]
根据这些评审意见修改论文
```

**修订协议（#390 Patch Protocol）**：
1. 锚定原草稿（每个块得到稳定标记）
2. 绑定明确的修订授权
3. 生成当前补丁（只触碰明确要改的块）
4. 确定性应用（未触碰的块字节级不变）
5. 持续证据记录

---

### 第 7 步：验证修订质量

**技能**：`academic-paper-reviewer`
**模式**：`re-review`
**输入**：原评审路线图 + 修订后的论文 + （可选）回复信
**产出**：
- 可追溯性矩阵（每条评审意见 → 是否回应 → 证据位置）
- 残留问题清单
- 新编辑决策

**怎么做**：
```
Verification review: check if revisions addressed the comments
验证审查：检查修订是否回应了评审意见
```

**三阶段证据合同（#576）**：
1. 标准承诺（修订盲）
2. 证据裁决（说服盲）
3. 声明匹配（回复信揭示）

---

### 第 8 步：投稿准备

**技能**：`academic-paper`
**模式**：`format-convert` + `disclosure`
**输入**：最终论文
**产出**：
- 目标格式文件（LaTeX / DOCX / PDF）
- 转换后的引用格式
- AI 使用声明（适配目标期刊政策）

**怎么做**：
```
Convert this paper to LaTeX format
把这篇论文转成 LaTeX 格式

Generate AI usage disclosure for [期刊名]
为[期刊名]生成 AI 使用声明
```

## 路径 B：从 0 到 1 发一篇中文论文（轻量中文线）

> 适用场景：中文期刊 / 学位论文 / 课程论文，需要飞书文档协作

### 第 1 步：中文学术文献调研

**技能**：`doubao-academic-researcher`
**输入**：研究方向或主题
**产出**：
- 核心结论
- 按维度的进展分析
- 争议与空白
- 可研究方向
- 经核验的参考文献
- 一段连续综述正文示例（面向大方向的格式示例）
- 飞书云文档（含文献地图表格、核心逻辑图）

**4 阶段自动执行**：
1. literature-scout（系统检索 + 引用核验）
2. research-synthesis（主题聚类 + 6 维门禁）
3. review-writing（综述正文示例）
4. document-delivery（飞书文档交付）

---

### 第 2 步：评估研究想法（可选）

**技能**：`doubao-academic-evaluator`
**模式**：想法评估
**产出**：可行性判断 + 新颖性检查 + 打分

---

### 第 3 步：写中文论文

**技能**：`doubao-academic-polish`
**线**：`write-zh`
**输入**：研究问题 + 调研结果 + （可选）你的材料
**产出**：
- 完整中文论文
- 飞书文档
- 读回校验报告

**Makefile 三阶段**：
1. `prepare` — 读材料、判定学科范式、来源核验
2. `write` — 按学科结构写 Markdown 源稿 + 正文检查
3. `deliver` — 生成终稿、创建飞书、读回校验

---

### 第 4 步：投稿前审查

**技能**：`doubao-academic-evaluator`
**模式**：投稿前审查
**产出**：硬伤清单 + 能不能投的判断 + 修改方向

---

### 第 5 步：语言润色与微调

**技能**：`doubao-academic-polish`
**线**：`shape` 润色模式
**产出**：润色后的最终稿

---

## 路径 C：已有论文草稿，投稿前自检 + 模拟评审

> 适用场景：论文已经写得差不多了，投稿前想做全面检查

### 第 1 步：快速挑硬伤

**技能**：`doubao-academic-evaluator`
**模式**：投稿前审查
**产出**：
- 致命缺陷清单
- 五维打分
- 分章审阅要点
- 能不能投的判断

---

### 第 2 步：模拟正式 5 人同行评审

**技能**：`academic-paper-reviewer`
**模式**：`full`
**产出**：5 份评审报告 + 编辑决策 + 修订路线图

---

### 第 3 步：根据评审意见修订

**技能**：`academic-paper`（revision 模式）或 `doubao-academic-polish`
**产出**：修订后的论文

---

### 第 4 步：验证修订质量

**技能**：`academic-paper-reviewer`
**模式**：`re-review`
**产出**：验证报告 + 新决策

---

### 第 5 步：引用检查 + 格式整理

**技能**：`academic-paper`
**模式**：`citation-check` + `format-convert`
**产出**：引用错误报告 + 最终格式文件

---

## 路径 D：读论文 + 找研究方向（学生日常场景）

> 适用场景：研究生入门、组会准备、开题前的方向探索

### 第 1 步：深度精读一篇关键论文

**技能**：`doubao-paper-close-reading`
**输入**：一篇具体论文（PDF/链接/标题）
**产出**：
- 一句话核心贡献
- 研究故事重建（问题→缺口→洞察→方法→证据→结论）
- 方法/理论机制拆解
- 关键实验与证据深读
- 可信边界与复现风险
- 研究启示与后续问题
- 高级 Markdown 报告 + 飞书文档

---

### 第 2 步：快速比较这个方向的 3 篇核心论文

**技能**：`deep-research`
**模式**：`three-way-scan`
**产出**：比较矩阵（方法/数据/结果/贡献/局限）

---

### 第 3 步：系统摸清这个研究方向的全貌

**技能**：`doubao-academic-researcher` 或 `deep-research`（lit-review 模式）
**产出**：
- 领域发展脉络
- 核心工作梳理
- 争议与共识
- 研究空白识别
- 可研究方向建议

---

### 第 4 步：引导式思考，从空白中找到自己的研究问题

**技能**：`deep-research`
**模式**：`socratic`
**产出**：精炼后的研究问题 + 方法论建议

---

### 第 5 步：评估找到的研究问题

**技能**：`doubao-academic-evaluator`
**模式**：想法评估
**产出**：新颖性 + 可行性 + 风险评估

---

## 工作流选择指南

| 你的情况 | 推荐路径 |
|----------|----------|
| 投英文期刊/SCI/顶会，从 0 开始 | 路径 A（英文系重型管线） |
| 投中文期刊/写学位论文，从 0 开始 | 路径 B（中文系轻量线） |
| 已有草稿，投稿前全面检查 | 路径 C（自检+评审+修订） |
| 学生读论文+找方向 | 路径 D（精读+比较+调研+引导） |
| 不确定 | 先用路径 D 摸清方向，再选 A 或 B |

> 💡 **捷径**：如果走路径 A 且不想手动一步步来，直接用 `academic-pipeline`，它会自动调度第 1-8 步的全部流程。
